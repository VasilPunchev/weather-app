# 🌦️ Weather App v2

A modern, responsive weather application built with JavaScript, HTML, and CSS, featuring real-time data, dynamic UI, and improved user experience.

🌐 **Live Demo:** https://weather-app.raccoon.bg/


### 🌍 Core Functionality

* Search weather by city name
* Search using **Enter key**
* Get weather for your **current location** (Geolocation API)

### 💾 Data & Storage

* Recently searched cities saved in **localStorage**
* Remove individual cities
* Clear all search history

### 🌡️ Weather Details

* Current temperature
* **Feels like** temperature
* Local time of selected city

### 🎨 UI & UX

* Dynamic backgrounds based on weather conditions
* Day / night background logic
* Glassmorphism design
* Fully responsive layout
* Loading states and smooth UX

### ⚠️ Error Handling

* Empty input validation
* Invalid city handling
* Location permission errors

## 🚀 Getting Started

### 🌐 Use Online

👉 https://weather-app.raccoon.bg/

### 💻 Run Locally

1. Clone the repository
2. Open the project folder
3. Add your OpenWeather API key in `app.js`
4. Open `index.html` with Live Server or any static server
