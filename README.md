# 🌦️ Weather App v2

A modern, responsive weather application with enhanced features and improved user experience.

🔗 **Live Demo:** https://weather-app.raccoon.bg/

---

## 🚀 What's New in v2

* Improved UI and smoother user experience
* Enhanced error handling and edge case coverage
* Better performance when fetching weather data
* More refined dynamic backgrounds
* Improved localStorage management for recent searches

---

## ✨ Features

* 🔍 Search weather by city name
* ⌨️ Search using **Enter key**
* 📍 Get weather for your **current location** (Geolocation API)
* 🕘 **Recently searched cities** saved in localStorage
* ❌ Remove individual cities from history
* 🧹 Clear all recent searches
* 🌡️ Displays **"feels like" temperature**
* 🎨 **Dynamic backgrounds** based on weather conditions
* 🌙 Day / night background logic based on city's local time
* 🕐 Shows **local time** of selected city
* ⏳ Loading state while fetching data
* ⚠️ Error handling (invalid input, city not found, location denied)
* 🧊 Glassmorphism UI design
* 📱 Fully responsive layout
* 🌐 Custom favicon

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
* OpenWeather API

---

## 🧪 Getting Started

1. Clone the repository
2. Open the project folder
3. Add your OpenWeather API key in `app.js`
4. Open `index.html` with Live Server
